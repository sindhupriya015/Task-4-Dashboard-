# Task 4 - Dashboard Design

## Objective
Designed an interactive sales dashboard using Tableau to help business stakeholders analyze sales, profit, quantity and trends.

## Tool Used
Tableau

## Dataset
Sales Dataset

## Key KPIs
- Total Sales
- Total Profit
- Total Quantity

## Visualizations
- Monthly Sales Trend
- Sales by Category
- Profit by Sub-Category
- Sales by State
- Sales Map
- Payment Mode Analysis

## Interactivity
Filters were added for:
- Category
- State
- Payment Mode
- Order Date

## Outcome
The dashboard helps stakeholders understand sales performance, identify trends and make data-driven business decisions.
